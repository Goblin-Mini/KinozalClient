Платежи: ручное подтверждение

Сейчас панель выдаёт лицензию после того, как администратор самостоятельно проверит оплату. Автоматическое получение заказов, статусы платежей, возвраты и чеки подключим отдельным этапом после выбора платёжного провайдера. Панель не показывает фиктивные платежи.

Данные загружаются непосредственно из Cloudflare D1 через защищённый Worker API.
